What every file does

  • Shows the game straight away, with no loading screen, and puts a goal and a tutorial hand on screen in the first second.
  • One round with a twist, then an end card. Hint, round and end card together take 20 to 30 seconds.
  • The store button calls the network’s own API: mraid.open on AppLovin and Unity, FbPlayableAd.onCTAClick on Meta, ExitApi.exit on Google.
  • Waits for MRAID ready and viewable, and pauses with its sound when the ad is hidden.
  • Silent until the first tap. Every sound is synthesised in code, so there are no audio files.
  • Portrait and landscape, with text and buttons kept clear of the bands where networks draw their own controls.
  • Zero network requests. Everything is inside the one file; the only URL is Google’s required exitapi.js in the Google build.

How it was measured: each network file was opened in headless Chrome inside a stub of its ad container, at 390×844 and 844×390, eight runs per sample. “First frame” is the time from the container’s go signal until the game is drawn. Sizes are the files as built. On this page the phones run the browser build, which falls back to a plain link for the store button.
