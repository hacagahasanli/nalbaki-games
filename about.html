One developer.
No pretending

Nalbaki Games is an independent studio. One developer designs, builds, tests and ships every game and every client project, working with modern tools, including AI-assisted coding, to move fast without cutting corners.

Nalbaki nal-BAH-kee

The games are for anyone with a browser. The mark is a slashed N: one cut, mid-motion, the moment a round turns.

What the studio makes

Original games that run in the browser: no install, no account, playable on a laptop or a phone a few seconds after you open the link. The first three, Parking Lot, Hazefall and Pewfield, each try a different genre and are being prepared for web game portals such as CrazyGames.

The same skills are for hire: custom browser games, three.js and WebGL work, playable ads and portal-ready builds, each sold as a fixed-price package.

How the work is done

  • Rules first, then pictures. Game logic lives in a plain simulation with its own automated tests, so the rules can be checked without opening a browser.
  • Phones are not an afterthought. Touch controls and phone layouts are part of every game.
  • Measure, then claim. Build size, load time and frame rate are measured and written down. The case studies list where every number comes from.
  • You own what you pay for. Client projects end with the full source code and notes, not a locked build.

What you will not find here

No stock-photo team, no borrowed client logos and no testimonials. The studio is new, so the portfolio is its own games. When there are client projects to show, they will appear with the client’s permission.
